# Sala Del Equipo De Abastecimiento

Este archivo es la sala fija para conversar con el equipo. Escribe o reemplaza el contenido bajo `## Consulta` y ejecuta:

```powershell
python equipo.py --room SALA_EQUIPO.md --consensus
```

En el chat de Codex tambien puedes decir:

```text
Equipo: usa SALA_EQUIPO.md
```

## Consulta

Revisar cobertura critica, riesgos de reposicion y errores de compra relevantes.

## Protocolo

1. El Jefe enruta la consulta.
2. Los analistas primarios ejecutan su revision en paralelo cuando hay mas de un dominio.
3. Revisores independientes validan calidad de datos, consistencia financiera, riesgo clinico y discrepancias.
4. El Jefe entrega consensos, observaciones y decision recomendada.
